# EVAplate Website Media Assets

## Required Images

### /hero/
- `hero-bg.mp4` — Assembly animation from Fusion 360 (recommended: 1920x1080, H.264, <10MB)
- `hero-poster.jpg` — First frame or key frame as fallback image (1920x1080)

### /products/
- `evaplate100.jpg` — EVAplate 100 product render from Fusion 360 (recommended: 800x600)
- `evaplate1000.jpg` — EVAplate 1000 product render from Fusion 360 (recommended: 800x600)

### /process/
- `process-overview.jpg` — Vacuum evaporation process diagram (AI-generated or technical illustration)

### /about/
- Factory/environment images (AI-generated via Nano Banana 2)

## Image Guidelines

- **Format**: JPG for photos/renders, PNG for diagrams with transparency, WebP for best compression
- **Video**: MP4 with H.264 codec, keep under 10MB for fast loading
- **Product renders**: Use white or transparent background from Fusion 360
- **AI images**: Generate at highest quality, then compress for web
